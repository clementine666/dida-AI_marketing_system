# 系统设计方案 v2 · 演示用一页摘要

> 团队演示开场 · 2026-09-07

---

## 我们要建什么

**道旅营销协作系统** = 画板六阶段 SOP 的数字化管控中枢：策划 → 建档 → 任务 → 审核 → 监控 → 档案，**6 个 Agent 工作台** + **系统管理**。

---

## 业务总流程（六阶段）

```
① 策划评审 → ② 建档看板 → ③ 任务进展 → ④ T-1审核 → ⑤ 监控推送 → ⑥ 档案库
                                                                    ↓
                                                              反哺 ①
```

**三条原则**：业务优先 · 人机协同（AI 辅助、人工闸门）· 骨架先行（细节后填）

---

## 系统模块（6+1）

| # | 模块 | 对应阶段 | 一句话 |
|---|---|---|---|
| 1 | 营销策划 Agent | ① | 评审池、AI 创意、日历定稿 |
| 2 | 方案策划 Agent | ② | 建档、看板、任务池 |
| 3 | 任务监督 Agent | ③ | 三线看板、催办、验收 |
| 4 | 上线审核 Agent | ④ | T-1 提醒、Checklist |
| 5 | 监控优化 Agent | ⑤ | 看板、T+1 总结 |
| 6 | 复盘归档 Agent | ⑥ | 知识库、问答反哺 |
| + | 系统管理 | — | 模块总览、日志、占位配置 |

---

## 业务 ↔ 系统（演示对照）

| 业务 | 系统 |
|---|---|
| 评审池采纳活动 | proposal → adopted |
| 活动建档 | activity_id + 主档 |
| 资源/素材/营销任务 | 三线任务板 |
| 任务验收通过 | ready_launch |
| T-1 审核通过 | live |
| 下线复盘归档 | archive → 反哺策划 |
