## 一、阶段 1：营销活动策划和评审（Wiki 原文）

### 1.1 活动生成

| 项 | 内容 |
|---|---|
| 负责人 | 军军、AI小组 |
| 任务所属类型 | AI小组 |
| 任务 | 2027年营销日历规划；①定义标准活动 ②标准活动日历表头字段 |
| 交付要求 | **标准活动**：国庆、五一、春节、泼水节、端午、暑假、寒假等大型节假日。**字段**：活动主题名称、活动类型（标准活动）、推广月份、上线位置、上线推广时间、目的地归属（大洲）、国家/地区、城市、热门商圈、选择理由 |
| 对接人 | Jim |
| 备注 | 标准型=本来就要做；创意型=洞察需求后做的创意活动 |

### 1.2 合并进入评审池

| 项 | 内容 |
|---|---|
| 任务 | 2027营销日历；①定义创意活动 ②创意活动表头 ③创意主题类型数量 |
| 交付要求 | **创意活动**：大数据洞察共性需求→产品推广机会（亲子、美食、赛车、演唱会、滑雪、樱花、康养、研学、潜水、摄影等）。**字段**：活动主题名称、活动类型（创意活动）、活动主题词、数据分析洞察、需求背景、业务契机、机会判断、活动创意、客户群体画像、需求规模、目标设定、酒店产品画像、推广月份、上线位置、上线推广时间、目的地（大洲/国家/城市/商圈）、选择理由 |
| 对接人 | Jim |
| 备注 | ①创意格式服务于评审评估 ②便于 AI 读取与总结 |

### 1.3 部门内初审

| 项 | 内容 |
|---|---|
| 任务所属类型 | AI创意活动提示词 |
| 交付要求 | 活动名称、上线时间、目的地（城市）、活动类型（标准/创意）、客群、酒店画像 |
| 负责人 | 初版 AI 部门；后续 JIM 调优 |
| 备注 | 营销活动负责人按需求调优提示词维度 |

### 1.4 初版日历生成

| 项 | 内容 |
|---|---|
| 任务 | ①人工规划 2027 初版是否需评审 ②评审角色/评审人 |

### 1.5 跨部门终审

| 项 | 内容 |
|---|---|
| 任务 | 日历点击活动名进入的活动文档字段，是否与营销日历规划字段一致 |
| 备注 | 日历视图 = 规划字段；点进活动 = 同字段展开为完整方案 |
