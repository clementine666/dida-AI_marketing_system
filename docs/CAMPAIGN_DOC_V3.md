## 五件事

| # | 你要的能力 | 文档层 | Agent |
|---|------------|--------|--------|
| 1 | 评审为什么做、要不要做 | 1–9 决策 | 营销策划 |

| 5 | 补人工结论形成最终归档 | 13 归档冻结整份文档 | 复盘归档 |

## 第四件事：AI 怎么追根因

读包固定三块，不扫散文：

1. **假设**：为什么做、圈谁、选什么酒店、玩法位置、目标与过程 KPI、窗口  
2. **过程+结果**：曝光→点击→转化→订单，TTV/GP  
3. **执行保真**：任务完成率、锁定 ID 是否空、素材预览是否在  

根因必须归类：圈客 / 供给 / 素材CTR / 券玩法 / 位置 / 档期 / 埋点缺失 / 任务没做完。

规则：任务没做完不先怪客群；没写过程指标只能判定无法归因。

接口：`POST /api/v2/activities/{id}/diagnosis`  
页面：复盘归档Agent → 生成根因分析 → 填人工结论 → 确认归档。

归档硬拦：`archive.human_conclusion` 为空则不能归档。入库内容 = 主文档 + 诊断 + 结论。
