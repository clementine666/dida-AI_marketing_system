# 道旅营销协作系统 · 同事接手说明

## 1. 本机启动

```powershell
cd multi-agent-marketing-system
py -3.11 -m pip install -r requirements.txt
py -3.11 -m app.main
```

浏览器打开：**http://127.0.0.1:8000/**（不要用 `/ui/dashboard/` 尾斜杠，会 404）

开发热重载：`py -3.11 -m app.main --reload`

## 2. 同 WiFi 局域网访问

服务默认监听 `0.0.0.0:8000`。同事手机/电脑与你在同一 WiFi 时：

```
http://<你的电脑局域网IP>:8000/
```

示例：`http://172.16.16.45:8000/`

查看本机 IP（PowerShell）：

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.InterfaceAlias -match 'WLAN|Wi-Fi|以太网' }
```

**Windows 防火墙**：若同事打不开，在本机以管理员运行：

```powershell
netsh advfirewall firewall add rule name="MarketingSystem8000" dir=in action=allow protocol=TCP localport=8000
```

## 3. 目录说明

| 路径 | 说明 |
|------|------|
| `app/` | FastAPI 后端、Agent 服务 |
| `ui/dashboard/` | 前端工作台（app.js / agent1_fields.js / agent2_fields.js） |
| `config/` | 模块与 Prompt 配置 |
| `docs/` | 设计文档、SOP、Jim 字段沟通 Excel |
| `data/` | Mock 数据、SQLite 库（若有） |
| `scripts/` | 迁移、演示数据、Excel 生成脚本 |

## 4. 演示数据

工作台 → 全年计划池 / 活动建档 → **「加载演示数据」**，或 API：

```http
POST http://127.0.0.1:8000/api/v2/demo/seed-agent2-case
Content-Type: application/json

{"force": true}
```

## 5. 环境变量（可选）

复制 `.env.example` 为 `.env`（若存在），配置飞书/数仓真实连接；未配置时使用 Mock。
