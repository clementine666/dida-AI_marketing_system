1. **A 定单元**：按归属洲汇总离店TTV，每洲取TOP5分析单元（洲二或国家）
2. **B 定月份**：每单元取离店TTV占比TOP3月份（阈值≥6%）
3. **C 定P75**：从「提前预订P75」表取目标离店月的月度P75
